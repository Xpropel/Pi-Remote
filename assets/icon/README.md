# pi-remote icon

The project icon: the pi π pixel mark, with a detached block and a dotted trail at the upper right for the remote side of the product.

## Files

- `pi-remote-icon.svg`, `pi-remote-icon-<size>.png` — badge version on a dark rounded background. Use for app icons, avatars, and store listings.
- `pi-remote-icon-nobg.svg`, `pi-remote-icon-nobg-<size>.png` — transparent version. Use in documents and web pages.
- `variants/` — the same mark in color, day, grey, and night colorways, each as SVG plus PNG renders.

PNG sizes: 32, 64, 128, 256, 512, 1024.
